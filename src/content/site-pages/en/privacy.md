Effective date: August 11, 2026.

This Privacy Policy explains the current information flows for 4all.tools. It
describes the application as it is operated today; a future feature may have
different behavior and should provide its own relevant explanation.

## Browser tools

The current JSON Validator performs validation, formatting, and minification in
your browser. Its core actions do not send the JSON you enter to an application
server. The application does not save that input in cookies, `localStorage`, or
`sessionStorage`. Copying a result uses your browser’s clipboard API only when
you choose the Copy action and the browser permits it.

Other tools may have different data flows. Check the tool’s own explanation
before entering information that is confidential, personal, or otherwise
sensitive.

## Cookies, analytics, and external resources

The application does not intentionally set cookies or use `localStorage` or
`sessionStorage` for its current public pages. It does not include a current
analytics or advertising system, and no application telemetry is intended by
this site. The built pages use the site’s own static assets; no external runtime
script or API is required for the current JSON Validator.

The hosting or delivery provider may process technical request information, such
as an IP address, request time, user agent, or error details, in infrastructure
logs. Those logs are controlled by the provider and may be subject to its own
retention and privacy practices.

## Contact messages

If you email [hello@4all.tools](mailto:hello@4all.tools), we receive the address
and the contents of your message, along with any information you choose to
include. The email provider and mail-delivery service may also process the
message. Please do not include passwords, payment details, or sensitive files
unless they are necessary for the inquiry.

We use contact correspondence to read and respond to the request, investigate
reported problems, and make requested content corrections. We keep it only as
long as reasonably needed for those purposes and any related record-keeping;
there is no promise of a fixed retention period for every message.

## Your requests and policy changes

For a privacy question or a request about correspondence, contact
[hello@4all.tools](mailto:hello@4all.tools). We can act on information we
control, but provider-managed infrastructure logs may follow the provider’s own
retention rules. We may update this policy when the site’s data flows change;
the current version and effective date will be shown on this page.
