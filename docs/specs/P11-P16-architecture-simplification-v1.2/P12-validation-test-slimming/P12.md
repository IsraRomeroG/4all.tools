# P12 — Validation and Test Guardrail Slimming

> **Phase ID:** `P12`  
> **Version:** 1.2.0  
> **Status:** Ready  
> **Depends on:** P11 Complete  
> **Risk:** Medium

## Purpose

Reduce the cost of changing internal architecture by removing project-owned validation that duplicates TypeScript/Astro/build behavior or tests textual implementation details.

P12 keeps high-value cross-entity validation and transfers page/render proof to real build output before deleting composition simulation.

## Keep

Architecture validation for durable data/model invariants such as:

```text
duplicate content identity
unknown tool/content identity
unknown taxonomy reference
article translation category mismatch
orphan/missing published tool module
unknown/unpublished relations
route collisions and invalid public route records
```

During P12, also keep validation for inconsistent **live** route-definition states that still exist in production. Those checks are removed only when P15 removes the underlying RouteDefinition model.

Keep a cheap direct filesystem invariant that `src/views` does not exist; do not retain an import graph merely for that rule.

## Remove

- custom source graph/import parser;
- graph-based source-boundary dependency validation;
- page-by-page architecture composition simulation after equivalent generic build proof exists;
- architecture-level SEO revalidation already covered by production composition/build tests;
- tests requiring source text to contain specific implementation strings;
- deep-freeze behavior as a project-wide contract.

## Definition of Done

- architecture validator focuses on catalog/cross-entity invariants;
- `npm run validate:architecture` remains available but substantially smaller;
- no custom import parser recursively scans project source;
- the `src/views` prohibition remains cheaply enforced;
- build remains authority for page renderability;
- generic route/build invariants protect every current RouteRecord;
- tests tolerate correct internal refactors;
- no new lint/dependency-analysis package is added;
- `npm ci && npm run verify` passes.
